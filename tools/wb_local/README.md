# Локальная проверка WB через Playwright

Этап 1: запускается только на компьютере оператора; сервер и Google Apps Script не меняются. Используется отдельный профиль Chromium, в который оператор входит вручную.

Проверяем запрос `https://www.wildberries.ru/__internal/catalog/sellers/v4/catalog`, ответ браузера и возможность получить цену повторным запросом с того же ПК. Cookie и Bearer не выводятся в лог и не передаются на VPS.

Программа локального теста добавляется отдельным коммитом. Huckster остаётся выключенным.
