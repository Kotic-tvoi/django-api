# Локальный тест Wildberries (этап 1)

Открывает отдельное окно Chromium, даёт вручную авторизоваться и проверяет фактический запрос каталога Wildberries. Затем на ЭТОМ ЖЕ компьютере повторяет один GET-запрос и показывает до пяти конечных цен.

Сейчас **не отправляет Cookie/Bearer на сервер**, **не меняет Google Apps Script** и **не использует Huckster**. Учётные данные не выводятся в консоль. Авторизация хранится в отдельном локальном профиле `%USERPROFILE%\.wb-price-playwright-profile` (этот каталог нельзя загружать в Git).

## Установка на Windows

1. Установи Python 3.11+ и открой PowerShell в корне клонированного репозитория.
2. Выполни:

```powershell
python -m pip install playwright requests
python -m playwright install chromium
python tools/wb_local/wb_local_test.py
```

3. В открывшемся браузере выполни вход на WB. Вернись в PowerShell и нажми Enter.
4. В консоли появятся статус запроса браузера, статус повторного GET и примеры цен в рублях. Полные заголовки и Cookies не показываются.

Примеры параметров: `python tools/wb_local/wb_local_test.py --seller 215484 --dest 1259571021 --brand 279103`.

При наличии установленного Chrome можно добавить `--chrome`; используется отдельный профиль, а не открытый обычный Chrome.

## Как интерпретировать результаты

- Browser catalog status 200 + Direct local GET status 200 + Prices > 0: локальное получение цен подтверждено.
- Browser catalog status 200, но повторный GET 401/403: перенос заголовков может быть недостаточен; на VPS может быть другая ситуация из-за IP.
- Нет browser catalog status: WB мог изменить запрос или страница продавца не загрузилась.
- 200 без товаров: проверь бренд, партнёра, регион и содержимое ответа.

На следующем этапе (только после локального подтверждения) внедряем безопасную синхронизацию авторизации с Django на VPS и проверяем запрос с серверного IP. После этого — Google Apps Script.

**Замечание:** Запрос использует внутренний endpoint сайта, не официальный API. Работа зависит от изменений WB. Не следует пытаться обходить блокировку доступа или защиту сайта.
